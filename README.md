# Subhajit Mitra — Personal Portfolio

A lightweight, responsive static portfolio website built with vanilla HTML, CSS, and JavaScript.

## Files Included
- `index.html` — Page structure and content
- `styles.css` — Dark/light theme variables, responsive layout, and component styling
- `script.js` — Theme persistence, project category filtering, clipboard copy with toast notifications, and contact form handling

## How to Run Locally
1. Unzip the archive.
2. Double-click `index.html` to open it in any modern browser.

## How to Deploy
You can host this folder for free on any static host:
- **Netlify Drop:** Drag and drop the unzipped folder into [app.netlify.com/drop](https://app.netlify.com/drop).
- **GitHub Pages:** Push the files to a GitHub repository and enable GitHub Pages in **Settings > Pages**.
- **Vercel:** Run `vercel` inside the folder or import the repository.
